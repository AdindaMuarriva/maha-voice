# maha-voice

## Environment

Tambahkan `VITE_API_BASE_URL` jika backend tidak berjalan di `http://localhost:5000/api`.

Contoh:

```bash
VITE_API_BASE_URL=http://localhost:5000/api
```

Frontend chatbot sekarang terhubung ke backend chat API dan akan menyimpan riwayat percakapan ke tabel `chatbot` di Supabase.
